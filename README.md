# Movie Player - FiveM YouTube/Twitch ビデオプレイヤー

FiveM用のビデオ視聴スクリプトです。ゲーム内でYouTubeとTwitchの動画を視聴・共有できます。

## 機能

- `/watch` コマンドでURL入力画面を表示
- **YouTube動画に対応**
- **Twitchライブ配信・VOD・クリップに対応** (DUI技術使用)
- **近くの人に共有** - 付近のプレイヤーに同じ動画を共有（受け取る側が承諾してから再生）
- **再生位置の同期** - 共有した人（ホスト）の一時停止・シークが、いっしょに観ている全員に反映される
- **参加の申請** - 近くで上映している人に「いっしょに観たい」と申請し、ホストが許可・拒否する
- **動画の枠** - 一時停止・シークバー・音量・枠の大きさ（10%刻み）を枠の中で操作
- **空間スクリーン** - 街の中の好きな場所にスクリーンを置いて、近くにいる人みんなで観る。心の目（ALT）で操作
- 視聴中はその場から動かない（ボイスチャットの発話とチャットは使える。設定で切り替え）
- ペーストボタンでURL簡単入力
- ESCキーまたは×ボタンで閉じる

## インストール方法

1. このリポジトリの中身を `movie-player` という名前のフォルダにして、`resources` ディレクトリにコピー
2. `server.cfg` に以下を追加:
   ```
   ensure movie-player
   ```
3. サーバーを再起動

旧名の `tani-watch` から乗り換えるときは、古い `tani-watch` フォルダを消して（または `server.cfg` の `ensure tani-watch` を外して）から入れてください。両方を同時に動かすと、`/watch` などのコマンドが重なります。キー設定（承諾・辞退のキー）と「共有を受け取る」の設定は、リソース名が変わるため初期値に戻ります。

## 使用方法

### 個人で視聴
1. ゲーム内で `/watch` を入力
2. URL入力画面が表示される
3. YouTubeまたはTwitchのURLを貼り付け
4. 「再生」ボタンをクリック（またはEnterキー）
5. 動画が画面中央に表示される

### 近くの人に共有
1. ゲーム内で `/watch` を入力
2. URLを貼り付け
3. 「近くの人に共有」ボタンをクリック
4. 付近のプレイヤー一覧が表示される（50m以内。開いている間は2秒ごとに自動更新）
5. 共有したいプレイヤーをクリックして選択（複数選択可。「全選択」も使えます）
6. 「○人に共有」ボタンをクリック
7. 共有した本人も同じ動画を再生し、相手には承諾確認が出る
8. 相手が視聴・辞退した結果は、画面右側の通知で届く

### 共有を受け取る
- 動画が共有されると、画面上部に確認が出ます。**承諾するまで再生も入力の奪取もしません。**
- 「視聴する」ボタン、または `Y` キーで視聴開始。「辞退」ボタン、または `N` キーで辞退（初期設定のキー。`ESC` → 設定 → キー割り当て → FiveM から変更できます）
- 15秒以内に応答しないと辞退扱いになります
- `/watchdnd` または入力画面の「共有を受け取る」スイッチで、受信のオン/オフを切り替えられます（設定はクライアントに保存されます）
- `/watchblock` で、最後に共有してきた人からの共有をブロックできます（再接続するまで有効）

### 視聴画面の枠
- 動画のまわりに枠が出ます。上の段に再生中の表示と「戻る」「閉じる」、下の段に一時停止・再生位置・音量・枠の大きさがあります
- 枠の大きさは `−` / `＋` で 10% ずつ変えられます（50%〜）。上限は画面に収まる大きさまでで、1920×1080 なら 130%、1280×720 なら 110% です。大きさは次に開いたときも同じです
- 枠は動画の外側だけを囲み、動画の上には何も重ねません（通知は枠の右の余白、確認は上の余白に出ます）
- 視聴中はその場から動けません（`Config.AllowMovementWhileWatching = true` で歩く・運転するを許可できます）。ボイスチャットの発話キーとチャットは使えます

### いっしょに観る（再生位置の同期）
- 共有した人がホストになり、承諾した人・参加を許可された人がいっしょに観ます
- ホストの一時停止・シークは、参加者全員に反映されます。参加者は一時停止・シークできず、**音量だけ**自分で変えられます
- ずれが `Config.SyncToleranceSec`（2秒）を超えたら、ホストの再生位置に合わせ直します（`Config.SyncIntervalMs` ごとに確認）
- ホストが閉じる・「戻る」で上映は終わり、参加者はそのまま（同期せずに）再生を続けます
- ライブ配信と Twitch のクリップは、再生位置を合わせません（ライブはもともと同じ場面が流れます）

### 参加を申請する
1. `/watch` を開くと、近く（`Config.NearbyDistance` 以内）で上映している人が「近くで上映中」に出ます
2. 「参加を申請」を押すと、ホストの画面に確認が出ます
3. ホストが「許可」（`Y`）すると、その場で再生が始まり、ホストの再生位置に合わせます。「拒否」（`N`）または 15 秒の時間切れで、申請した人に知らせます
- ひとりで観ているときも上映として扱うので、近くの人から申請が届きます。いらなければ拒否してください

### 空間スクリーン
1. `/watch` の「空間にスクリーンを置く」（または `/watchscreen`）で配置を始めます。URL を入れておくと、置いたスクリーンでそのまま再生します
2. 置きたい場所を狙うと、スクリーンの大きさの枠がハイライトされます。**緑なら置ける、赤なら置けない**（理由は画面下に出ます）
   - 壁を狙うと壁に貼り、床を狙うと自分の方を向けて立てます（天井なら吊るします）
   - マウスホイールで大きさ、`↑` / `↓` で高さ、`Q` / `E` で向き（床・天井のとき）
   - 左クリック（または Enter）で置く、右クリック（または Backspace・ESC）でやめる
3. 置いたスクリーンは、近くにいる人全員に見え、全員が同じ再生位置で観ます。音は近いほど大きく、`Config.Screens.AudioDistance`（25m）で聞こえなくなります
4. スクリーンを狙って心の目（ALT、ox_target）を使うと、次の操作ができます
   - **スクリーンを操作する**（全員）: 自分だけの音量。置いた人と管理者は、一時停止・シーク・動画の変更・動画を外す・撤去もできます
   - **スクリーンの位置・大きさを変える**（置いた人と管理者）: 配置と同じ操作で動かします
- 置けるのは 1 人 2 枚まで（`Config.Screens.MaxPerPlayer`）。管理者（ACE 権限 `movieplayer.admin`）は上限なしで、どのスクリーンでも変更・撤去できます
- スクリーンはサーバーを再起動すると消えます（保存しません）
- ox_target が無いサーバーでは、`/watchscreenmenu` で近くのスクリーンの操作パネルを開けます

### 閉じ方
- ESCキー
- ×ボタン
- 「戻る」ボタンでURL入力画面に戻る

## コマンドとキー

| 操作 | 内容 |
| --- | --- |
| `/watch` | URL入力画面を開く |
| `/watchdnd` | 共有の受信をオン/オフ |
| `/watchblock` | 最後に共有してきた人をブロック |
| `/watchscreen` | 空間にスクリーンを置く |
| `/watchscreenmenu` | 狙っている（なければいちばん近い）スクリーンの操作パネルを開く |
| `Y`（初期） | 共有された動画を視聴する・参加の申請を許可する |
| `N`（初期） | 共有された動画を辞退する・参加の申請を拒否する |
| ALT（心の目） | スクリーンを狙って、操作パネル・位置の変更 |

`N` は音声チャットの発話キーと重なることがあります。重なる場合は `config.lua` の `Config.DeclineKey` か、FiveM のキー設定で変更してください。

## 対応URL形式

URLは「許可したホストと形式に完全一致するもの」だけ受け付け、動画ID・チャンネル名などを取り出して作り直したURLだけを使います。`https://` が無くても貼り付けられます。

### YouTube
- `https://www.youtube.com/watch?v=VIDEO_ID`
- `https://youtu.be/VIDEO_ID`
- `https://www.youtube.com/shorts/VIDEO_ID`
- `https://www.youtube.com/live/VIDEO_ID`
- `https://www.youtube.com/embed/VIDEO_ID`
- `m.youtube.com` / `music.youtube.com` も可

### Twitch
- ライブ配信: `https://www.twitch.tv/CHANNEL_NAME`（`?sr=a` などのクエリ付きも可）
- VOD: `https://www.twitch.tv/videos/VIDEO_ID`
- クリップ: `https://www.twitch.tv/CHANNEL/clip/CLIP_ID`
- クリップ: `https://clips.twitch.tv/CLIP_ID`

## 技術仕様

このスクリプトは **DUI (DirectUI)** 技術を使用しています。これにより：

- FiveM NUI環境のCSP (Content Security Policy) 制限を回避
- Twitch埋め込みプレイヤーが正常に動作
- ゲーム内3D空間にビデオをレンダリング可能

動画は画面の縦横比に合わせて 16:9 のまま描画します（ウルトラワイドでも歪みません）。

| `Config.Debug` | `false` | `true` で詳細ログを出す |
| `Config.NearbyDistance` | `50.0` | 付近プレイヤーの検出距離（メートル）。参加を申請できる上映の範囲にも使う |
| `Config.MaxShareTargets` | `10` | 1回の共有で選べる最大人数 |
| `Config.ShareCooldownMs` | `5000` | 同じ送信者の共有間隔の下限（ミリ秒） |
| `Config.ServerDistanceCheck` | `true` | サーバー側でも距離を検証する（OneSync 必須） |
| `Config.ServerDistanceMargin` | `15.0` | サーバー側の距離検証に足す余裕（メートル） |
| `Config.RequireAcceptance` | `true` | 受け取る側に承諾確認を出す。`false` にすると届いた動画を即再生する |
| `Config.ShareRequestTimeoutMs` | `15000` | 承諾確認の待ち時間（ミリ秒） |
| `Config.AllowGameInputWhileWatching` | `true` | 視聴中もキーボードの入力をゲームへ渡す（ボイスチャットの発話キーなどを使えるようにする） |
| `Config.AllowMovementWhileWatching` | `false` | 視聴中に歩く・走る・運転するを許可する |
| `Config.ControlsAllowedWhileWatching` | `{ 245, 249 }` | 移動を止めている間も使えるコントロール（チャット・ボイスチャットの発話） |
| `Config.AcceptKey` / `Config.DeclineKey` | `Y` / `N` | 承諾・辞退（参加の申請の許可・拒否）のキーの初期値 |
| `Config.VideoWidth` | `0.62` | 動画の幅（画面の幅に対する割合）。縦横比によっては高さの上限で小さくなる |
| `Config.VideoMaxHeight` | `0.62` | 動画の高さの上限（画面の高さに対する割合） |
| `Config.VideoCenterY` | `0.55` | 動画の中心の縦位置（0 = 上端、1 = 下端）。上に通知用の余白を残すため中央より少し下 |
| `Config.FrameScaleMin` / `Config.FrameScaleMax` / `Config.FrameScaleStep` | `0.5` / `1.5` / `0.1` | 枠の大きさの範囲と刻み。上限は画面に収まる大きさで頭打ちになる |
| `Config.SyncIntervalMs` | `3000` | 再生位置を確かめる間隔（ミリ秒） |
| `Config.SyncToleranceSec` | `2.0` | これ以上ずれたらホストに合わせ直す（秒） |
| `Config.JoinRequestEnabled` | `true` | 参加の申請を使う |
| `Config.JoinRequestTimeoutMs` | `15000` | 申請の待ち時間（ミリ秒） |
| `Config.JoinRequestCooldownMs` | `8000` | 同じ人の申請の間隔の下限（ミリ秒） |
| `Config.MaxSessionMembers` | `30` | 1つの上映に参加できる最大人数（ホストを含む） |
| `Config.MaxUrlLength` | `300` | 受け付けるURLの最大長 |
| `Config.DuiWidth` / `Config.DuiHeight` | `1280` / `720` | DUI解像度 |
| `Config.DuiReadyTimeoutMs` | `8000` | DUI の準備を待つ上限（ミリ秒） |

空間スクリーンの設定は `Config.Screens` にまとめています。

| 設定 | 初期値 | 内容 |
| --- | --- | --- |
| `Enabled` | `true` | 空間スクリーンを使う |
| `MaxPerPlayer` | `2` | 1人が置けるスクリーンの数（管理者は無制限） |
| `AdminAce` | `movieplayer.admin` | 管理者として扱う ACE 権限。例: `add_ace group.admin movieplayer.admin allow` |

| `InteractDistance` | `8.0` | 心の目（ALT）で操作できる距離（メートル） |
| `RemoveOnOwnerDrop` | `false` | 置いた人が退出したら撤去する |
| `ActionCooldownMs` | `1500` | 置く・動かす・動画の変更の間隔の下限（ミリ秒） |

## セキュリティ

共有のイベントは、クライアントから届く値を信用せず、サーバー側で検証します。

- 送信者の名前とIDは、サーバーが `source` から取得します（クライアントの申告は使いません）
- URLは `shared.lua` で許可リストと完全一致で検証し、正規化したURLだけを中継します（`youtube.com` を含むだけの別サイトのURLは通りません）
- 共有先は、型・件数の上限・在線・重複・距離（OneSync 時）を検証します
- 同じ送信者の連続共有は `Config.ShareCooldownMs` で制限します
- 受け取る側でもURLを再検証し、承諾するまで再生や入力の奪取をしません
- 上映の一時停止・シークは、サーバーが「その上映のホストか」を確かめてから参加者へ中継します。参加の申請は、ホスト本人の許可だけを受け付け、時間切れ・距離・間隔・人数の上限も検証します
- 空間スクリーンの位置・幅・向きは数値として検証し、置く人から `Config.Screens.PlaceDistance` 以内（OneSync 時）に限ります。変更・撤去・一時停止・シークは、置いた人（license で判定）と管理者だけが行えます

**外部サーバーへの通信について**: 動画を再生するとき、プレイヤーのPCが YouTube（`www.youtube.com`）または Twitch（`player.twitch.tv` / `clips.twitch.tv`）へ直接接続します。これらのスクリプトは配信元が更新するため SRI（改ざん検知）は付けられません。動画を再生しない限り外部へは接続しません。UI フォント（Outfit）はリソースに同梱しており、Google Fonts へは接続しません。

**OneSync について**: サーバー側の距離検証は OneSync が有効なサーバーでのみ働きます。サーバーから座標を取れない環境では、距離の検証だけを自動でスキップします（他の検証は常に有効です）。

## YouTube・Twitch の利用について

本リソースは、動画の再生に **YouTube API サービス（IFrame Player API）** と **Twitch の埋め込みプレイヤー** を使います。動画を再生する利用者は、次の規約・ポリシーが適用されます。サーバーのルールにも明記してください。

- YouTube 利用規約: <https://www.youtube.com/t/terms>
- Google プライバシーポリシー: <https://policies.google.com/privacy>
- Twitch 利用規約: <https://legal.twitch.com/legal/terms-of-service/>
- Twitch プライバシーに関する通知: <https://legal.twitch.com/legal/privacy-notice/>

**サーバー運営者の方へ**

- **視聴を有料にしないでください。** YouTube API サービスの利用規約は、埋め込みプレイヤーでの視聴を有料にすることを禁じています（入場券の販売など）。Cfx.re の Creator Platform License Agreement も、商用利用の方法を制限しています
- **上映するコンテンツの権利は、運営者と視聴者の責任で確認してください。** 権利の確認されていない映画や中継を、サーバーで流す使い方は想定していません
- 動画の再生を妨げる改変（広告の非表示、プレイヤーの隠蔽、映像と音声の分離、ダウンロードなど）は、YouTube の規約で禁じられています。本リソースは、これらをしていません
- 通知や共有の確認は、動画の上に重ならないよう、動画の外側（上の余白・枠の右の余白）に出します。枠の操作（一時停止・シークバー・音量・大きさ）も、動画の外側の上下の段に置いています。YouTube の埋め込み要件（プレイヤーの上に表示物を重ねない）に合わせた設計です。独自に表示物を足すときも、動画の範囲には置かないでください

## 注意事項

- YouTubeの一部の動画は埋め込みが無効になっている場合があります（理由は画面に表示されます）
- Twitchの一部コンテンツは地域制限がある場合があります
- Twitchのクリップは、埋め込みの仕様上、音量の操作ができません
- 共有は `Config.NearbyDistance` 以内のプレイヤーにのみ可能です
- 動画は画面の中央より少し下に、枠に囲まれて表示されます（上と左右に通知用の余白を残します）
- YouTube プレイヤー自身のボタンは、ゲーム内では操作できません（マウス操作を DUI に渡していないため）。一時停止・シーク・音量は、枠の下の段で操作します
- 再生位置の同期は、ずれが 2 秒を超えたら合わせ直す方式です。動画の読み込みや広告で、一時的にずれることがあります
- 空間スクリーンは、1 枚につき DUI（ブラウザ）を 1 つ使います。同時に再生するのは近い `Config.Screens.MaxActive` 枚までで、ほかは黒い画面で表示します。多くすると重くなります
- 空間スクリーンには当たり判定がありません（歩いて通り抜けられます）。心の目（ALT）は、視線がスクリーンの面に当たっているかで判定します
- リソースのフォルダ名を変えても動作します（リソース名は実行時に取得します）
- 視聴中（`Config.AllowGameInputWhileWatching = true`）は、マウスのクリックが射撃・殴打として、マウスの移動がカメラの回転としてゲームに届かないよう、視点・攻撃・照準のコントロールを無効にしています。初期設定（`Config.AllowMovementWhileWatching = false`）では、移動のコントロールも無効にして、チャットとボイスチャットの発話だけを残します
- YouTube と Twitch の埋め込みプレイヤーは、再生中に広告が表示されることがあります。Cfx.re の Creator Platform License Agreement（3.1 項 (7) が、ゲーム内への第三者の広告の組み込みを禁じています）との関係は、サーバー運営者が確認してください

### 4.0.0
- 【移動の停止】視聴画面を開いている間は、その場から動かないようにした（`Config.AllowMovementWhileWatching`。チャットとボイスチャットの発話は使える）

- キー設定の説明を「動画の共有・参加の申請を受ける / 断る」に変えた
